# 第一段：3C 与核心机制改造

更新时间：2026-10-07。对应 Dot-life 的第一段改造，不包含墨水功能实现、光影或 Toon 材质改造。

测试精简说明（2026-10-07）：旧阶段测试构建已清理，历史日志与核心回归工具保留；下文旧构建路径只代表当时记录。L1 光影已撤回，当前试玩入口以 ROADMAP 最新进度为准，不再使用 `Logs/LightingL1Build/DotLife.exe` 验证当前版本。

CharacterController 迁移已完成代码与原生回归。本轮按用户澄清撤回上一轮 E 打点误报相关的额外修改，放大 HUD，轻微降低模型显示高度，并在保留俯视倾角与滚轮缩放的基础上支持右键水平绕转。不新增任务、墨水、UI 美术或渲染效果；代码检查与实际手感验收分开记录。

## 当前规则

- 保留四项任务、各任务的打点顺序和绘制帧；日记仍自动绘制，完成日记后解锁三个原有跳下点。
- WASD / 方向键沿屏幕方向移动。主动交互仍用 E，一次只执行一个目标；可用任务点优先于边缘，再按距离选择。
- 主动打点/敲击会短暂停走，动画到接触时才提交结果；取消前未命中则不推进，已提交的结果不回滚。
- 所有绘制步骤接受后，等待绘制帧和现有结束过渡播完，才算任务完成；最后一个任务完成才结算。
- 游戏结束后不能用任意键重新开始，也不能重新交互；结束发生在跳下途中时，原轨迹继续完成，但不恢复输入。
- 普通游玩保持现有斜俯视倾角；按住鼠标右键左右拖动，可水平绕角色旋转，竖向鼠标移动不改变倾角。不绕墙、不自动拉近避障、不随角色转身旋转。W/方向上键随相机朝向更新，始终朝屏幕上方移动。
- 滚轮向前拉近，向后拉远，初始构图是最远端，最多拉近 4 个世界单位；旋转不改变这个距离范围。结尾仍使用原专用构图，不接受缩放或旋转。
- 模型显示下移 0.02 个世界单位以减少悬浮感；碰撞胶囊、角色根节点、动画曲线及跳下轨迹不改，场景文件不写入。

## 代码职责

| 模块 | 负责什么 | 不再负责什么 |
| --- | --- | --- |
| `InteractingHandler` | 唯一键盘/滚轮输入入口、目标选择、动作开始/接触提交/取消/超时恢复 | 不直接决定任务计数或切换材质 |
| `BasicBehaviourScript` | CharacterController 位移与转向、脚底接触、台阶/坡度参数、显式重力、角色动作状态及控制权限 | 不读取按键，不决定任务规则；不再使用 Rigidbody 或自写台阶抬升 |
| `InteractionTarget` | 识别玩家、记录多碰撞体进出、统一可执行接口 | 不自行读取 E；非玩家碰撞体不产生交互 |
| `DotDrawing` / `EdgeFalling` | 各自的有效性判断，把请求交给动作或跳下执行者 | 不独立抢输入、播放未经验证的动作 |
| `DotDrawingHandler` | 固定任务 ID、顺序/配置验证、步骤接受、绘制表现与最终完成 | 不再靠展示消息匹配任务，不因按下 E 就完成 |
| `TransitionHandler` / `TextureSurface` | 完成过渡与主贴图更新；同一 Renderer 共用一个受控材质实例 | 不分别创建材质实例，不直接触发全局胜利 |
| `GameState` / `TriggerBus` | 游戏等待/游玩/结束，任务完成幂等，汇总范围与任务结果，成对清理订阅 | 不轮询键盘；退出一个重叠区域不会清掉其他有效范围 |
| `CameraFollowingScript` / `TaskStatusBar` | 固定倾角平滑跟随、水平绕转、距离缩放、结尾镜头，以及权威目标/任务状态的显示与可读尺寸 | 镜头不做墙体回避；HUD 不自行挑一个边缘判断；结尾旋转不覆盖 Inspector 配置 |

游戏流程与角色动作分开：游戏为 Waiting / Playing / Finished；角色为 Locomotion / Interacting / Falling。不建立两者组合的大状态机。
