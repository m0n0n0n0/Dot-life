# 墨水机制：B1 / B2 使用与接入记录

更新：2026-10-07。B1 负责资源、蘸墨与跟随条；B2 已接入非任务区脚下自由盖印。最终验证与调参入口记录在本文，主观手感仍需试玩。

## 当前流程

1. 开始时持有 `日记点数 × stampCost` 的墨水，当前为 9。日记继续走上去自动打点，每个成功点消耗一次；其他任务在日记完成前不能打点。
2. 日记完成后墨水为零，三个原跳下点照常解锁，不需要墨水。原点位、贴图序列、跳下轨迹和落点不变。
3. 日记完成后进入 `ink_low` 的触发范围，墨水盒上方出现轻微上下浮动、朝向相机的 `E`；离开范围或游戏结束时隐藏，不再显示屏幕上的“按 E 蘸墨”。蘸墨动作接触时补满，动作结束恢复移动。此前取消、离开范围或失焦均不补充。
4. 其他任务继续按 E 打点或敲击，接触帧确认任务成功才扣墨。重复输入、错序、失败和取消不重复扣墨；普通走路不消耗、不留脚印。
5. 墨水条通常隐藏，包括墨水未满时。消耗时显示剩余量和消耗残影后淡出；蘸墨时短暂显示满条；无墨尝试手动打点时空条闪两次。白色底槽默认透明度 45%，描边只覆盖边缘，空槽可透出场景；墨水与消耗残影保持原颜色。结束后隐藏，重进场景恢复初始量。
6. 日记完成后，非任务区按 E 使用原 Tread 动作盖印。接触帧重新检查脚下位置，再生成一枚略不规则的墨点；成功才消耗一次墨水。初始九点已用完，所以正常流程先跳下并蘸墨。
7. E 优先处理蘸墨、可操作任务点与跳下，只有没有这些目标时才尝试自由盖印。未完成任务的承接表面和触发区保留给原任务；完成后的表面可以自由盖印，但不会增加或重新通知任务进度。游戏结束后不再盖印。
8. 墨点完整采样范围必须落在同一承接物上；跨纸边、过窄、明显曲率变化或空中均拒绝，不向下层补齐。位置过窄时短暂提示“此处无法盖印”，失败不扣墨；普通走路仍不留印。墨迹默认最多 128 枚，满后复用最旧的一枚；不跨场景保存。

左上角任务文案按“日记 → 语文书 → 数学书 → 照片”的第一个未完成任务常驻，离开点位、蘸墨或跳下时不消失。若提前完成后面的任务，轮到它时跳过；这里只改变文案选择，不新增任务顺序限制，也不附加步骤计数。开始与结束文案仍按游戏阶段显示。

## 职责与渲染方式

- `PlayerInk` 只管理资源和通知。`TryCommitStamp` 预留一次消耗，提交失败或抛异常恢复；同步重入被拒绝。回调必须先验证再一次性提交，不能依赖资源类撤销外部副作用。
- `InkWell` 只负责可操作条件，蘸墨复用 `InteractingHandler` 的动作、接触、取消与恢复，不重复读取 E。
- `UIPlayerInk` 只观察资源并投影到屏幕，`InkMeterGraphic` 只绘制圆角条。
- `InkStamping` 接自由动作与资源；`InkSurfaceSampler` 从角色胶囊中心脚底沿人物水平朝向偏移，再取最近实体表面，验证落印位置、法线和完整采样范围；`InkMark` 只持有自己的小网格与共享材质。任务顺序仍由原 `DotDrawingHandler` 判断。
- 任务区仍按原明确条件推进；普通自由墨迹不自动增加任务进度。墨迹创建成功才调用资源提交，失败不消耗。不新增背包或自然恢复。
- 本版用独立贴面网格覆盖墨迹，不改木材 / 纸面原贴图，也不添加 Decal Renderer Feature、Depth / Opaque Texture 或改全场渲染设置。之后替换原物体的 Toon 材质，墨点无需跟着改任务代码；描边时不要给墨点网格额外画外壳线。
- 墨迹顶点取承接物局部坐标，跟随刚体式位置 / 旋转 / 缩放变化。它没有实体碰撞，不成为下一次盖印的地面；清空、承接物销毁和场景卸载时释放自建网格，不生成逐枚材质实例。

## 表面与性能边界

| 情况 | 当前处理 / 注意 |
| --- | --- |
| 上层纸张叠在桌面 | 最近实体命中优先；被禁止或排除的上层物体也会阻挡，不透过去画到下面 |
| 角色靠侧面的探地射线仍显示 grounded，但落印中心处是缝隙 | 盖印单独检查偏移后的落印中心与完整范围，不能借旁边支撑点把墨点落到缝隙下方 |
| 原碰撞体比模型更宽 | 额外核对启用的可见 Renderer 范围；隐形外沿拒绝盖印，不改原碰撞体。该检查是包围盒保护，并非逐像素 / 精确美术网格裁切 |
| 曲面、细缝和复杂几何 | 网格顶点和三角形中心采样，不能保证捕捉任意小于采样间距的孔洞。优先让碰撞匹配模型；必要时缩小直径、增加细分或禁止该物体盖印，不默认修改 FBX 可读写设置 |
| 已有任务纸面 | 未完成时保护整个承接表面，避免自由印盖住教学图案；完成后仍要有完整可承接范围 |
| 蒙皮变形、透明复杂模型、动画形变表面 | 未承诺自动适配；当前验证针对静态 / 刚体变换表面，特殊物件单独验证 |
| 大量墨迹 | 默认一枚 49 顶点、72 三角形，128 枚至多 9,216 三角形，共享材质但仍有多个透明 Renderer。上限控制增长不等于免费；目标机 GPU / 过绘制、批次与帧时间仍待测量 |

运行时墨迹挂在各自承接物下，不会全部列在同一个场景根节点中；这是为了跟随物件，退出 Play 后不会写入场景。

| 调整目标 | 调整入口 | 含义 |
| --- | --- | --- |
| 自由墨点落在脚下偏前 | 选中 `Assets/_DotLife/Player/Ink/INK_Default.asset`，Inspector 的 `Forward Offset` | 默认 0.2 个世界单位；正数沿人物当前朝向前移，0 恢复胶囊中心脚底，负数向后。可在 0.1～0.3 间微调；与相机朝向无关，运行时限制在 -0.5～0.5 |
